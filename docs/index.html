🫀 bioreco
GitHub Repository
Open-Source Biomedical Project

Making Human Organ Perception
Easier & Accessible

Bioreco is dedicated to building AI models and web applications that simplify human organ perception, providing advanced sensor fusion services combining Echography (ultrasound) imaging with 3D organ models.

Core Focus & Services

🫀 Organ Perception Models

Creating deep learning models for automated organ boundary detection, volumetric estimation, and anatomical feature recognition.

📡 Echography & 3D Fusion

Real-time spatial registration overlaying 2D ultrasound scans directly onto multi-planar 3D organ anatomical meshes.

🌐 Open Web Applications

Lightweight, accessible web tools enabling researchers and developers to visualize and interact with organ perception models.
